- Data base functionality and connection has been merged onto the main branch.
- Please see the comment in the "Data base" pull request for more details.
- The Entities folder contains classes automatically generated by Entity Framework Core through 
reverse engineering the existing BikeStore database. These classes represent the database tables, views, columns, and relationships required for database operations.
- Connection to the db should be possible provided your your branch was created from the main.
- LINQ and ENtity Framework Core should make interacting with the db simpler.
- SQL queries can be used but are not recommended as they are more complex and less efficient than LINQ.
- Add these to the headers of your forms' classes
```csharp
using BikeShop.Helpers;
using System.Linq;
```
- Example of code that retrieves every customer and its properties using LINQ and display it on a data grid.
```csharp
using var db = DatabaseHelper.CreateContext();
var customers = db.Customers.ToList();
dgvCustomers.DataSource = customers;
```
